📱 Mobile Setup (Android Chrome & iOS Safari)

Mobile browsers don't support drag-and-drop. Copy this one-line script and follow the 3 steps below:

1
Create a Bookmark: Tap your browser menu (⋮ on Chrome or Share button on Safari) and bookmark this page as Minutes Deals.
2
Edit the Bookmark: Open your Bookmarks list, tap Edit on Minutes Deals, delete the entire URL, and paste the copied script above. Save it.
3
Run on Flipkart: Open flipkart.com, tap the address bar, type Minutes Deals, and tap the bookmark suggestion that appears!
